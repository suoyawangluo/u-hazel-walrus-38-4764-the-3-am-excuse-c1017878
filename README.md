One line under 200 characters: the excuse a hardware wallet gives for
refusing to sign a transaction at 3 AM.

> My keys clocked out at midnight and my buttons are on strike — your 3 AM 'emergency' is just FOMO with a timestamp.

`main.ts` writes the line to `/output/entry.txt` (115 code points, 1 line)
and verifies it against the gate (1–200 characters, not only whitespace).
